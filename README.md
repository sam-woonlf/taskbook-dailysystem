# 任务清单 · TaskBook

一个纯前端的个人任务管理工具（单文件应用），无需构建、无需服务器，打开 `index.html` 即用；
线上地址为作者发布、保持更新的官方版本，可以直接使用；
若作为个人开发者想在此基础上DIY，可读下列说明，项目已完全开源。

线上地址：https://taskbook-dailysystem.netlify.app

## 功能

- **今日清单**：逾期、今日到期、无期限、每日固定四类分组；"新增任务"收起为一个按钮，点击展开快速添加。
- **任务库**：按分类、状态筛选，支持标题搜索、编辑、删除、归档与恢复。
- **统计**：今日汇总卡片（已完成 / 待办 / 完成率 / 逾期）、**目标进度**、按截止日的**月历视图**（可翻月、点击查看当天任务）、近 30 天完成趋势。
- **目标**：设定起止日期与一组可重复任务（每日，或每周指定几天），目标任务按周期出现在今日清单的「每日固定任务」里；进度按**完成次数 / 自动推算的应完成次数**统计，达成即盖「已达成」并停止，过期自动结束、完成率保留。可撤销最近一次打卡、随时结束或删除目标。
- **专注浮窗**：番茄钟做成右下角浮窗按钮，可拖动换位；收起时显示剩余倒计时，点击展开使用，切到任何页面都能继续计时。
- **模板清单**：把常用的一组任务存成模板；每个模板任务可单独设置小任务、具体时间和备注，添加后也能随时删除。
- **小任务与备注**：任务可拆分多个小步骤，可写备注；小任务不计入主任务完成率。
- **账号同步（可选）**：配置 Supabase 后可跨设备同步，未登录时数据只保存在本机浏览器。
- **数据管理**：导出 / 导入 JSON 备份，清空数据需二次确认。
- **全站动效**：首屏入场、任务增删改反馈、面板与弹窗过渡、日历翻月、统计数字滚动等，并支持系统"减少动态效果"设置。

## 使用方式

1. 直接用浏览器打开 `index.html`；或部署到任意静态托管（当前线上为 Netlify）。
2. 首次打开可点右上角「使用说明」查看完整操作指引。
3. 需要跨设备同步时：
   - 在 [supabase.com](https://supabase.com) 新建免费项目；
   - 执行 `supabase-setup.sql`；
   - 把项目 URL 与 anon key 填入 `index.html` 顶部的 `SUPABASE_URL` / `SUPABASE_ANON_KEY`。

## 数据与隐私

- 未登录时，任务数据只保存在当前浏览器（localStorage），不上传任何服务器。
- 登录账号后，数据同步到你自己的 Supabase 项目。
- 换电脑或清理浏览器数据前，建议先在「管理 → 数据管理」导出 JSON 备份。

## 技术说明

- 无构建步骤、无第三方运行时依赖（仅可选的 Supabase JS SDK 通过 CDN 引入）。
- 自适应桌面与手机端布局。
